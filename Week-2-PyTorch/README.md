# Week 2: Deep Learning with PyTorch

Skill Set Go EduTech | AI/ML Internship

## Objective
Develop practical deep-learning skills using PyTorch through neural-network training, CNN image classification, and controlled hyperparameter experiments.

## Dataset
MNIST handwritten digits (54,000 train / 6,000 validation / 10,000 test).

## Tasks Completed
- 2.1 Neural Network in PyTorch
- 2.2 CNN Image Classifier
- 2.3 Hyperparameter Experimentation
- 2.4 Deep Learning Technical Report

## Tools
Python, PyTorch, Torchvision, NumPy, Pandas, Matplotlib, Scikit-learn, Google Colab

## Results
- Feed-forward network test accuracy: 96.90%
- CNN test accuracy: 98.78%
- Best experiment: Adam, lr 0.001, batch size 128 (98.42% validation), tied with batch size 64 (98.40%)
- SGD (lr 0.001) reached 92.22% and Adam (lr 0.01) reached 97.05%

- AbdUrRahman_Week2_Deep_Learning_PyTorch.ipynb (notebook with outputs)
- Deep_Learning_Technical_Report.pdf

## How to Run
Open the notebook in Google Colab (T4 GPU recommended) and run all cells from top to bottom. MNIST downloads automatically.
